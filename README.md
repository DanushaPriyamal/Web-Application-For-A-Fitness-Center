# 👨‍💻 Web Application For A Fitness Center
**Monolithic Architecture used web application for a fitness center called as "FitZone Fitness Center"**

---

## ✨ Features
- **User Interface**
    - Sign Up for a user account
    - Sign Up for the fitness center membership
    - Enter queries for further details
    - View blog posts
    - View details of certified trainers
    - Register for group classes
    - View query responses

- **Admin Interface**
    - View membership sign ups
    - View group class registrations
    - View queries
    - Reply to queries

---

## 💻 Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL

---

## 🛠️ Development Tools
- Visual Studio Code
- XAMPP
